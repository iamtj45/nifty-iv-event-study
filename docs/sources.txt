# Documents the question box answers from.
#
#   python fetch_docs.py
#
# One per line:   DATE | KIND | URL
#
#   DATE   the event date, YYYY-MM-DD, matching data/events.csv
#   KIND   RBI or BUDGET
#   URL    a direct link to the PDF
#
# Where to find them:
#
#   RBI     rbi.org.in -> Press Releases -> the Monetary Policy Statement for
#           that meeting. Open it, then copy the link to the PDF itself (the
#           address should start with rbidocs.rbi.org.in and end in .PDF).
#
#   Budget  indiabudget.gov.in -> the year you want -> Budget Speech.
#           Only the current year sits at a predictable address; older ones
#           are in the archive section.
#
# Lines starting with # are ignored, so you can work through this list a few
# at a time and re-run fetch_docs.py whenever you like. Already-downloaded
# files are skipped.
#
# ---------------------------------------------------------------------------
# One example, already filled in, so you can check the format works:

2025-12-05 | RBI | https://rbidocs.rbi.org.in/rdocs/PressRelease/PDFs/PR16331051154700094ACFB40DE08AE141531C.PDF
