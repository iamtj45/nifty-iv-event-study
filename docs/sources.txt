# Documents the question box answers from.
#
#   python fetch_docs.py
#
# One per line:   DATE | KIND | URL
#
#   DATE   the event date, YYYY-MM-DD, matching data/events.csv
#   KIND   RBI or BUDGET
#   URL    a direct link to the PDF
#
# All 28 documents for the 29 events in data/events.csv are listed below, in
# the same order. Nothing here is downloaded until you run fetch_docs.py, and
# files already in docs/ are skipped, so re-running it is safe and cheap.
#
# ---------------------------------------------------------------------------
# Where these came from, and how to add the next one.
#
# RBI. Each entry is the MPC *Resolution* -- not the Governor's Statement and
# not the Minutes, which are separate press releases published alongside it.
# The resolution is the document that states the repo rate, the stance and the
# vote, which is what a question about a meeting is actually asking for.
#
# The filenames are opaque hashes with no pattern, so they cannot be
# constructed -- each one has to be read off RBI's own listing. For a new
# meeting: rbi.org.in -> Press Releases -> pick the month -> find "Monetary
# Policy Statement, <year> Resolution of the Monetary Policy Committee" and
# copy the address of the PDF icon beside it. It should start with
# rbidocs.rbi.org.in and end in .PDF.
#
# The title carries the meeting's dates, e.g. "September 29 to October 1,
# 2025". The DATE below is the *last* of those -- the announcement day, which
# is the day events.csv records and the day the IV crush happens.
#
# Budget. Archived years sit at a stable address:
#
#     indiabudget.gov.in/budget<FY>/doc/Budget_Speech.pdf
#
# with "(I)" appended to the financial year for an interim budget, as in
# budget2024-25(I). Note the capitals in Budget_Speech.pdf -- the server is
# case-sensitive and the lowercase spelling 404s on the archived years.
#
# The current year is the exception: it is served from the site root at
# /doc/Budget_Speech.pdf and moves to an archive path when the next Budget
# replaces it. So the 2026-02-01 line below will need changing to
# budget2026-27/doc/Budget_Speech.pdf once the 2027-28 Budget is presented.
#
# One caution. rbidocs.rbi.org.in sits behind a bot check that sometimes
# answers a script with a JavaScript challenge instead of the PDF.
# fetch_docs.py verifies that what came back really is a PDF and reports the
# file as failed rather than saving the challenge page, so a run that reports
# failures is usually worth simply retrying rather than debugging.
#
# Lines starting with # are ignored, so you can work through this a few at a
# time if you prefer.
# ---------------------------------------------------------------------------
